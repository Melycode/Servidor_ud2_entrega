# Gestión de Conciertos y Entradas (UD2)

Proyecto desarrollado en Python para la gestión de conciertos, usuarios y control de venta de entradas aplicando Programación Orientada a Objetos (POO).

## Características del Proyecto
* **Jerarquía de Clases:** Gestión de clases para `Concierto`, `Usuario` y tipos de entradas (`Grada`, `Pista`, `VIP`).
* **Control de Errores:** Validación de aforos, estados de conciertos, edades y valoraciones mediante excepciones (`raise Exception`).
* **Estadísticas:** Cálculo de totales, recaudación y precios medios mediante bucles acumuladores.

## 💻 Tecnologías
* Python (POO, bucles, excepciones, herencia).
* Git & GitHub (Control de versiones).
